## Security Operations Lifecycle

```text
01  TELEMETRY       → Validate logging, coverage, event quality, and timestamps
02  DETECTION       → Review alert logic, severity, indicators, and context
03  TRIAGE          → Prioritise, validate, and establish initial scope
04  INVESTIGATION   → Correlate evidence and build an event timeline
05  CONTAINMENT     → Coordinate proportionate actions to limit impact
06  RECOVERY        → Validate remediation and monitor for recurrence
07  LESSONS LEARNED → Document root cause and improve detections/playbooks
```
